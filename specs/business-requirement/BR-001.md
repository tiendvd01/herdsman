# Business Requirement — Herdsman

> **Thiết kế UI:** [Herdsman UI (canvas)](https://claude.ai/artifact/G5Po8nsNnNB5taxkrSwRkQ). **Phong cách chọn: shadcn/ui minimal** (xem mục 3.2).
> - [shadcn/ui minimal — Light](https://claude.ai/artifact/G5Po8nsNnNB5taxkrSwRkQ#play-Shadcn) / [Dark](https://claude.ai/artifact/G5Po8nsNnNB5taxkrSwRkQ#play-ShadcnDark): **bản chính** về giao diện (màu, font, khoảng cách, component). Artboard vẽ theo mô hình cũ (chưa có workspace); bố cục màn hình theo mục 3.1.
> - [Worktree](https://claude.ai/artifact/G5Po8nsNnNB5taxkrSwRkQ#play-Worktree): các chỗ worktree hiện trong UI (badge branch, tạo, chuẩn bị, xoá, danh sách theo project). *Vẽ khi worktree còn gắn từng session; theo F11 thì phần này thuộc workspace.*

## 1. Bối cảnh & mục tiêu
Herdr app hiện chạy agent (Claude Code, Codex…) trong terminal và tổ chức công việc theo **space**. Cách làm này có hai hạn chế:
- Hội thoại của agent là giao diện TUI, nên **không render được Mermaid, bảng, biểu đồ hay markdown đầy đủ**.
- Công việc được gom theo space (bị gắn với một machine và một layout). Trong khi đó, người dùng thực tế nghĩ theo **project**.

**Herdsman** là app desktop (Tauri) giữ được điểm mạnh của Herdr là agent vẫn sống khi tắt app (persistent session, nhờ dùng `hc`/herdr-core làm nhân), nhưng:
1. Hiển thị hội thoại agent bằng **GUI**: markdown, Mermaid, biểu đồ, diff, card cho tool call.
2. Tổ chức theo **Project → Workspace → Session**, thay cho space:
   - **Project** là một đường dẫn thư mục trên máy local.
   - **Workspace** gom các session cùng làm một việc (ví dụ một issue cần nhiều session).
   - **Session** là một hội thoại với agent. Session nào cũng thuộc một workspace.

## 2. Người dùng
Lập trình viên chạy nhiều agent song song trên nhiều repo, hiện đang dùng Herdr/Claude Code/Codex.

## 3. Chức năng chính

| # | Chức năng | Mô tả |
|---|---|---|
| F1 | **Projects** | Thêm, sửa, xoá project bằng đường dẫn thư mục local (nút **+ Project mới** ở đầu sidebar). Sidebar liệt kê project → workspace, không còn khái niệm space. |
| F2 | **Agent session** | Mở session Claude (qua **Claude Agent SDK**) hoặc Codex trong một workspace. Session chạy trong thư mục làm việc của workspace, trong terminal của `hc`, nên **tắt app hoặc khởi động lại app thì session vẫn chạy**. Mở lại app là thấy đầy đủ, đang chạy tiếp. Các session của workspace hiện thành **hàng tab** phía trên hội thoại. |
| F3 | **Rich conversation view** | Stream hội thoại thành GUI theo thời gian thực (cả chữ đang chạy dở): markdown (GFM), code highlight, **Mermaid**, **biểu đồ** (khối ` ```chart ` / Vega-Lite), KaTeX, bảng. Tool call hiển thị thành card thu gọn được, `Edit`/`Write` hiển thị diff, có ảnh đính kèm. |
| F4 | **Gửi input** | Ô chat để gửi tin nhắn, dán ảnh, ngắt lượt (interrupt) và dùng slash command. Nút mở rộng (mũi tên chéo) làm ô chat cao lên để soạn text dài; bấm lại hoặc Esc để thu nhỏ. Khi mở rộng, ô chat cao 300px mặc định và kéo cạnh trên để đổi chiều cao (nhớ giữa các lần mở). |
| F5 | **Trạng thái & thông báo** | Hiện trạng thái idle / working / blocked / done / error của từng session theo realtime, bằng chấm màu trên tab session. Workspace có session đang chờ (blocked hoặc error) có chấm vàng cạnh tên ở sidebar. Gửi thông báo hệ điều hành khi agent xong hoặc cần duyệt. Không có danh sách "cần xử lý" riêng. |
| F6 | **Duyệt quyền (permission)** | Agent xin dùng tool thì GUI hiện hộp Allow/Deny kèm diff hoặc lệnh sẽ chạy. Nếu app đang tắt, agent đứng chờ (trạng thái `blocked`) đến khi mở lại app để duyệt. |
| F7 | **Log view** | Mỗi session có tab "Log" xem màn hình terminal của tiến trình agent (xterm.js) để debug. Session vẫn xem được bằng `hc read` / `hc attach`. |
| F8 | **Multi-agent** | Hiển thị cây agent cha → con (agent giao việc qua `hc run --bg`) và tiến độ của từng con. Không hiển thị tin nhắn giữa các agent. |
| F10 | **Lịch sử & tìm kiếm** | Tab History trong panel bên phải liệt kê các phiên Herdsman và Claude Code CLI của workspace hoặc toàn app, mới nhất ở trên. Tìm theo tiêu đề hoặc nội dung. Chọn phiên để xem hội thoại, với tab tạm cho phiên đã xong. |
| F11 | **Workspace** | Tạo bằng dấu **+** cạnh tên project. Mỗi lần tạo luôn sinh **một workspace mới kèm một session trống**, người dùng viết prompt đầu tiên ở session đó. Khi tạo, nhập: tên (để trống thì dùng tiêu đề tóm tắt của Claude khi có), thư mục làm việc là **worktree mới** (checkout riêng trên branch mới tạo từ nhánh mặc định hoặc branch local có sẵn chưa được checkout) hoặc **thư mục project**. Mọi session trong workspace dùng chung thư mục đó. Nút **+** cạnh hàng tab mở menu chọn loại session. |
| F12 | **Workspace terminal** | Chọn **Terminal** từ nút **+** cạnh hàng tab để mở shell tương tác tại thư mục làm việc của workspace. Shell tiếp tục chạy khi chuyển tab hoặc tắt app. Mở lại workspace để nối lại. Đóng tab terminal trực tiếp dừng shell và lệnh đang chạy trong đó. |

### 3.1 Bố cục màn hình
- **Sidebar trái:** tên app · nút **+ Project mới** · danh sách project → workspace (dấu + cạnh tên project để tạo workspace; icon branch là workspace có worktree, ô vuông là dùng thư mục project; chấm vàng khi có session đang chờ) · trạng thái `hc` và nút Settings (bánh răng, ⌘,) ở dưới cùng; Settings mở hộp thoại đè lên app, mục Appearance gồm theme, font giao diện và font code.
- **Khung giữa:**
  - Hàng workspace: `project › workspace`, chip branch hoặc "thư mục project", trạng thái session đang mở, model, ctx.
  - Hàng tab session: chỉ hiện session chưa xong (và session đang xem), tab terminal, nút + mở menu, icon lịch sử.
  - Hội thoại và ô nhập. Session vừa tạo hiện màn chờ prompt đầu tiên.
- **Sidebar phải:** Agents, Files, Git, Log.

### 3.2 Phong cách giao diện — shadcn/ui minimal
Toàn bộ UI theo phong cách **shadcn/ui minimal** trong artifact (artboard Shadcn / ShadcnDark):
- **Màu:** nền trung tính thang zinc (Light: nền trắng `#FFFFFF`/`#FAFAFA`, viền `#E4E4E7`, chữ `#09090B`, chữ phụ `#71717A`; Dark: nền `#09090B`/`#18181B`, viền `#27272A`, chữ `#FAFAFA`). Không dùng gradient; màu chỉ dành cho trạng thái: xanh lá (working/done), vàng (blocked/chờ duyệt), đỏ (error).
- **Chữ:** Geist cho giao diện, Geist Mono cho code, đường dẫn, branch, lệnh, log và số liệu (model, ctx).
- **Hình khối:** viền mảnh 1px thay cho bóng đổ; bo góc nhỏ (6px cho nút/ô nhập/card, 8–12px cho panel/hộp thoại, tròn cho chấm trạng thái và badge).
- **Component:** dùng bộ shadcn/ui (Button, Input, Tabs, Dialog, Badge, Card, ScrollArea, Tooltip…), mật độ gọn, ưu tiên chữ và icon nét mảnh.
- **Thanh cuộn:** mảnh (8px, phần kéo 4px), không mũi tên, màu xám tương phản với nền theo theme (tối hơn ở Light, sáng hơn ở Dark; vùng Log nền tối luôn dùng màu sáng).
- **Theme:** có Light và Dark, đổi trong Settings → Appearance (hoặc ⌘⇧L); mặc định theo hệ điều hành.
- **Font:** mặc định Geist / Geist Mono; người dùng đổi được font giao diện và font code trong Settings → Appearance (chỉ font đóng gói hoặc có sẵn trên máy, không tải từ mạng).
- Thiết kế cũ (bản Main, File panel, Mô hình workspace) không còn dùng; khi artboard shadcn thiếu màn hình nào (workspace, file panel, duyệt quyền…) thì vẽ bổ sung theo cùng phong cách.

## 4. Yêu cầu phi chức năng
- **Persistence:** trạng thái chạy thuộc về `hc` (đã sống qua việc tắt app, update và restart core). App phải tự kết nối lại khi mở.
- **Không mất dữ liệu:** mỗi session có event log riêng; transcript gốc của engine (`~/.claude`, `~/.codex`) vẫn được giữ để resume khi tiến trình agent chết.
- **Hiệu năng:** stream mượt với hội thoại dài trên 5.000 message (virtual list), render Mermaid/chart lười (lazy).
- **Tương thích:** session hiện trong `hc ls` / Herdr với đúng trạng thái; agent khác giao việc được qua `hc send`; session Claude resume được bằng `claude --resume`.
- **Nền tảng:** ưu tiên macOS, sau đó Linux.

## 5. Ngoài phạm vi (v1)
- Tự viết engine agent hay gọi API trực tiếp.
- **Mods** (panel mở rộng theo project) và chạy mod của Herdr (gpui).
- **Remote machine**: project nằm trên machine khác (`hc machine`). Phase này chỉ hỗ trợ project local.
- Đồng bộ cloud, đa người dùng.

## 6. Tiêu chí chấp nhận chính
- Tắt app trong lúc agent đang chạy, mở lại sau 10 phút: hội thoại đầy đủ, agent vẫn tiếp tục và trạng thái đúng.
- Agent trả lời có khối Mermaid thì GUI hiện sơ đồ; khối ` ```chart ` hiện thành biểu đồ.
- Agent xin quyền `Edit` thì GUI hiện diff; bấm Allow là agent chạy tiếp.
- Bấm + cạnh project, tạo workspace để trống tên: workspace có sẵn một session trống; gửi prompt đầu tiên thì session chạy. Workspace hiện “New workspace” cho đến khi Claude có tiêu đề tóm tắt.
- Hai workspace dùng worktree trong cùng project chạy song song, sửa file không đè lên nhau.
