# Research

- Use Codex App Server over stdio. Its documented thread, turn and approval lifecycle directly supports a rich desktop client. The TypeScript automation SDK was considered for simple prompts.
- Use the local CLI's credentials and official thread discovery. Reading raw rollout files would couple Herdsman to private storage details.
- Keep Codex under the existing hc-owned sidecar. A GUI-owned server would exit during a desktop restart.
