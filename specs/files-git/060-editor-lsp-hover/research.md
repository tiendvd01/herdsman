# Research — Editor LSP Hover

The TypeScript Language Server provides hover for JavaScript and TypeScript, including JSX and TSX. Its standard I/O connection can remain open while the editor needs it. CodeMirror's hover extension supplies positioning and dismissal, and the client validates asynchronous results against the active document. Workspace selection follows the actual backing path to avoid mixing drafts and project configuration across worktrees.

[TypeScript Language Server documentation](https://github.com/typescript-language-server/typescript-language-server)
