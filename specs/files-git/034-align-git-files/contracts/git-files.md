# Git Files UI Contract

- Chọn bằng chuột hoặc Enter mở và chọn tab Changes cho đường dẫn trong workspace hiện tại, giữ danh sách Git hiển thị.
- Chọn lại cùng file dùng lại tab. Tab editor và tab diff có thể cùng mở.
- Thanh tab dùng chung thao tác chuyển, đóng và thứ tự focus. Danh sách hiển thị trạng thái Git và cung cấp Refresh.
