# Quickstart

1. Chạy `pnpm typecheck`, `pnpm test` và `pnpm build` từ thư mục dự án.
2. Chạy `pnpm tauri dev` với môi trường desktop đã thiết lập. Mở workspace Git có hai file đổi trùng tên ở hai thư mục.
3. Mở Git và lần lượt chọn hai file bằng chuột và Enter. Kiểm tra diff đúng file, thanh tab chính có hai tab Changes và danh sách Git vẫn hiển thị. Chọn lại một file để kiểm tra dùng lại tab.
4. Mở editor cho một file, sửa chưa lưu, chuyển sang diff và đóng diff. Kiểm tra bản sửa trong editor.
5. So sánh tiêu đề, hàng file và trạng thái hover, focus, lựa chọn giữa Git và Files trong cả Light và Dark. Kiểm tra Refresh và workspace sạch.
