# Pull Request Notification Navigation

Chọn thông báo hoặc View trên toast để mở chi tiết trong app. Với nhiều project trùng repository, chọn project sẽ hoàn tất điều hướng và đánh dấu đã đọc. Khi tải thất bại, giữ màn chi tiết với thông báo lỗi, Back to list và Open on GitHub. Chỉ hành động Open on GitHub mới mở trang PR trên trình duyệt.
