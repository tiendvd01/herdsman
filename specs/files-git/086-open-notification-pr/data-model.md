# Data Model

- Thông báo gồm repository, event key, số PR, tiêu đề, trạng thái đọc và các project đích.
- Đích chi tiết dùng project, repository, số PR và tài khoản. Tiêu đề thông báo làm tiêu đề ban đầu khi chưa có metadata.
- Metadata chi tiết gồm tiêu đề hiện hành, trạng thái, draft, hai branch và thời điểm cập nhật. Đổi tài khoản hoặc project sẽ đóng chi tiết.
