# Quickstart

1. Chạy `pnpm test tests/unit/pullRequests.test.tsx` và `pnpm typecheck`.
2. Chạy `cargo test --manifest-path src-tauri/Cargo.toml pull_requests`.
3. Trên Herdsman desktop đã đăng nhập GitHub, chọn thông báo của một PR đã merge từ Notifications. Kiểm tra chi tiết mở trong Herdsman, hiện trạng thái Merged, rồi dùng Back to list để về tab Notifications.
4. Nếu cùng repository thuộc nhiều project, mở ở All projects, chọn project và kiểm tra trạng thái đã đọc. Kiểm tra Open on GitHub mở đúng PR khi bấm.
