# Research

- Dùng danh sách thay đổi theo workspace hiện tại. Duyệt thư mục trên đĩa sẽ bỏ sót file đã xóa, còn dữ liệu Git cung cấp đúng tập file.
- Dùng nút bật/tắt Tree view và các danh sách lồng nhau với nút mở thư mục. Cách này dùng lại Button, hỗ trợ Tab và Enter trực tiếp, và biểu thị trạng thái mở bằng thuộc tính truy cập.
- Dùng UI store hiện có để giữ chế độ qua các lần Git tab bị tháo khỏi giao diện. Trạng thái mở thư mục gắn với dòng thư mục, giúp làm mới dữ liệu mà giữ các dòng còn tồn tại.
