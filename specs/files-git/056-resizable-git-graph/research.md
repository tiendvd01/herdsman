# Research

- Read Git log in topological order from HEAD. Parent IDs support merge lanes and detached HEAD without interpreting Git terminal formatting. Plain commit lists omit ancestry.
- Reuse the shared horizontal resize handle and retain a proportional split in the mounted side panel. Native element resizing would bypass the shared keyboard behavior.
- Limit the initial view to the latest 200 commits and indicate the limit when there are older commits. This keeps the read and rendering bounded.
