# Pull Requests UI Contract

- Chi tiết đang mở có một nút `Back to list` phía trên vùng cuộn. Nút giữ vị trí khi cuộn và có focus rõ ràng.
- Kích hoạt bằng chuột hoặc bàn phím trả về danh sách theo nơi mở chi tiết như [spec](../spec.md). Nút hoạt động trong lúc tải hoặc tải lỗi.
- Khi danh sách trở lại, nút biến mất. `Open on GitHub` tiếp tục mở đúng PR.
