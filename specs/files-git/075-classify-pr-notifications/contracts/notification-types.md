# PR Notification UI Contract

Overview, Notifications và toast dùng chung bảng ánh xạ trong [đặc tả](../spec.md), với nhãn chữ tiếng Anh, biểu tượng và màu theo vai trò. Dữ liệu review chung hoặc loại chưa nhận diện dùng Info. Toast giữ mô tả sự kiện và hành động View. Trạng thái đọc và luồng điều hướng PR tiếp tục hoạt động.
