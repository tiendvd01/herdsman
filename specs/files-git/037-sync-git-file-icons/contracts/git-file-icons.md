# Git Changes UI Contract

- Mỗi dòng hiển thị icon Material ở đầu dòng theo tên file, kể cả đích đổi tên, file đã xóa và đuôi lạ.
- Icon có alt rỗng. Tên truy cập của dòng vẫn có đường dẫn và trạng thái Git.
- Ký hiệu ở cuối dòng, màu trạng thái và mở diff bằng chuột hoặc bàn phím tiếp tục hoạt động.
