# Data Model

- **Dòng thay đổi** — Đường dẫn và trạng thái Git hiện có. Thành phần cuối của đường dẫn là tên dùng để chọn icon. Với rename, đường dẫn hiện có là đích.
- **Icon file** — SVG Material trang trí được xác định từ tên file, theo cùng quy tắc như File Tree. Tên chưa nhận diện dùng icon mặc định.
