# Git Changes UI Contract

Nút tiếng Anh Tree view cho biết Tree đang bật hay tắt. Khi bật, mỗi thư mục là nút có trạng thái mở hoặc thu gọn. File nằm dưới thư mục cha và có tên truy cập kèm đường dẫn đầy đủ và trạng thái Git. Khi tắt, các dòng List hiển thị đường dẫn đầy đủ. Chọn file ở cả hai chế độ mở cùng diff.
