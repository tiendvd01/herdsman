# Settings UI Contract

**Settings → Appearance → Code font size** có một group cùng tên. Các phần theo thứ tự là nút **Decrease code font size**, giá trị **Current code font size** và nút **Increase code font size**. Nút khả dụng nhận focus qua Tab và hỗ trợ Enter/Space. Nút đi ra ngoài giới hạn bị vô hiệu hóa. **Reset** nằm cạnh khung và xuất hiện khi có lựa chọn riêng.
