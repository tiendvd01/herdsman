# Worktree Postscript Editor

- Trường Shell command hiển thị giá trị đã lưu hoặc văn bản trống.
- Enter xuống dòng, undo/redo chỉ sửa bản nháp, Tab di chuyển qua các nút của hộp thoại.
- Save gửi văn bản của editor cho project đang mở. Save lỗi giữ lại văn bản. Cancel bỏ bản nháp.
- Khởi chạy sau khi tạo worktree tuân theo [spec 084](../../084-worktree-postscript/spec.md).
