# Workspace session launcher

| Trạng thái | Hành động |
| --- | --- |
| Workspace đang hoạt động, đã tải, không có tab | Nút **Create new session** giữa vùng nội dung |
| Workspace đang hoạt động, có tab hoặc đang tải | Nút tạo session trên thanh tab |
| Workspace đã lưu trữ hoặc màn hình project | Hành động hiện tại của từng trạng thái |

Nút và phím tắt mở cùng menu. Chọn Claude Code hoặc Codex sẽ tạo và chọn session trong workspace hiện tại. Chọn Terminal mở tab terminal theo luồng sẵn có. Escape đóng menu.
