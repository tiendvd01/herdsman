# Quickstart

1. Mở Projects với GitHub đã đăng nhập và một worktree có PR cùng repo.
2. Kiểm tra số PR và biểu tượng nằm ngay dưới worktree trong theme sáng và tối. Dùng Tab để tới số PR và Enter để mở trên GitHub. Xác nhận workspace hiện tại vẫn được chọn.
3. Kiểm tra một nhánh có nhiều PR và một PR từ fork trùng tên nhánh. Làm mới Pull Requests sau khi merge và kiểm tra biểu tượng chuyển trạng thái.
4. Chạy `pnpm test`, `pnpm build` và `cargo test --manifest-path src-tauri/Cargo.toml pull_requests`.
