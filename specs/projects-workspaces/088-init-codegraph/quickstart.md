# Quickstart

1. Chạy `pnpm typecheck`, `pnpm test` và `cargo test --manifest-path src-tauri/Cargo.toml project_codegraph`.
2. Trong Herdsman desktop có hc và CodeGraph, mở Project options → CodeGraph Index trên một checkout Git thử nghiệm. Initialize và đóng/mở hộp thoại để xem trạng thái. Sau khi hoàn tất, xác nhận số liệu và Refresh index.
3. Kiểm tra Git status và exclude ở checkout chính hoặc linked worktree. Mở project đã có index chưa ignore để thử Add to local Git exclude.
