# UI Zoom Contract

| Thao tác | Kết quả |
| --- | --- |
| Mở app với tùy chọn mặc định hoặc đặt lại zoom | 100% với kích thước tương đương 110% cũ. |
| Tăng hoặc giảm | Chuyển một bậc theo danh sách trong [mô hình dữ liệu](../data-model.md) và dừng ở giới hạn. |
| Chỉnh riêng cỡ chữ | Cỡ chữ nội dung đổi. Nhãn zoom và kích thước khung giữ nguyên. |
| Mở app với tùy chọn đã lưu | Áp dụng cả hai giá trị trước khi hiển thị giao diện. |
| Đổi zoom khi đang làm việc | Giữ bản nháp, tab, vị trí đọc và chiều rộng panel đã lưu. Agent tiếp tục chạy. |
