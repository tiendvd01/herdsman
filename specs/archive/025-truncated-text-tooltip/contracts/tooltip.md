# Tooltip UI Contract

| Tương tác | Kết quả |
| --- | --- |
| Hover nhãn bị cắt | Hiện toàn bộ nội dung của nhãn đó. |
| Hover nhãn vừa khung | Tooltip chữ bị cắt tiếp tục đóng. |
| Rời nhãn hoặc nhấn Escape | Tooltip đóng. |
| Hover lại sau khi đổi kích thước hoặc nội dung | Xét lại việc cắt chữ theo bố cục hiện tại. |

Tooltip giữ nguyên vùng bố cục và thao tác của mục bên dưới. Nội dung dài ngắt dòng khi cần.
