# Data Model

Tool item hiện có mang tên công cụ, đầu vào, thông tin shell và kết quả nếu có. Với Bash, chi tiết ưu tiên trường `command` dạng chuỗi không rỗng. Giá trị được giữ nguyên cả khoảng trắng. Trường thiếu, sai kiểu hoặc chuỗi rỗng dùng biểu diễn đầu vào cũ. Thẻ được lưu và phát lại dùng cùng cấu trúc.
