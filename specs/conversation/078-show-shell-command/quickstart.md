# Quickstart validation

Từ thư mục gốc với dependencies đã cài, chạy `npm test -- tests/unit/toolCard.test.tsx tests/unit/render.test.tsx` và `npm run typecheck`.

Trong app, mở thẻ Bash có lệnh dài hoặc nhiều dòng, rồi đối chiếu văn bản chọn được với lệnh gốc. Kiểm tra khối lệnh dễ đọc, cuộn được ở theme sáng và tối, và status cùng output hiển thị riêng. Mở lại hội thoại đã lưu để kiểm tra cùng hành vi.
