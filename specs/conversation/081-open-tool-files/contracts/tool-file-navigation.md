# UI Contract

| Thao tác | Kết quả |
| --- | --- |
| Bấm hoặc dùng bàn phím kích hoạt đường dẫn trên Read hoặc Write | Files mở đúng tệp theo session, hoặc đưa tab hiện có ra trước và giữ bản nháp |
| Kích hoạt nút thu gọn | Nội dung code hoặc diff đổi trạng thái hiển thị |
| Mở tệp đã bị xóa hoặc đích không hợp lệ | Hội thoại hiển thị lỗi và giữ vị trí đọc |
