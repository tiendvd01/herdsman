# Quickstart

Chạy `npm test -- tests/unit/render.test.tsx` và `npm run typecheck`.

Trong app, mở hội thoại có khối code một dòng có nhãn, code nội tuyến, và một Edit có dòng thêm, xóa, ngữ cảnh. Đổi qua giao diện sáng và tối, kiểm tra màu cú pháp và dấu dòng. Thử một ngôn ngữ không hỗ trợ và kiểm tra văn bản nguồn.

Ở Settings → Appearance, thử 14 px, 18 px, mở lại app, rồi Reset. Kiểm tra ba loại code theo [UI contract](contracts/rich-conversation.md).
