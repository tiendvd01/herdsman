# Rich Conversation UI

- Khối code hiện ngay. Sau khi hoàn tất, nhãn ngôn ngữ hợp lệ cho màu cú pháp. Khối Mermaid và biểu đồ dùng trình hiển thị tương ứng.
- Diff dùng cú pháp theo tệp với cả dòng thêm, xóa và ngữ cảnh. Dấu dòng và màu trạng thái vẫn nhận diện được. Khi không lấy được màu, văn bản nguồn vẫn hiện.
- Code nội tuyến, khối code và dòng diff dùng Code font size hiện hành, gồm Default.
