# Data Model

- Khối code gồm văn bản và nhãn ngôn ngữ tùy chọn. Nội dung đang stream hiển thị ngay.
- Dòng diff gồm loại thêm, xóa hoặc ngữ cảnh, văn bản, và thông tin hunk/đường dẫn nếu có. Đường dẫn xác định ngôn ngữ. Hàng tiêu đề giữ văn bản thuần.
- Code font size dùng giá trị đã lưu hoặc Default. Dữ liệu tô màu chỉ phục vụ hiển thị.
