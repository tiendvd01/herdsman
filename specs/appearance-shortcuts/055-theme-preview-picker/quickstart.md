# Validation

1. Run `pnpm typecheck` and `pnpm test`.
2. Run `pnpm dev`, open Settings from the sidebar and select Appearance.
3. In Dark mode, choose Catppuccin Frappé and One Dark Pro. Compare each preview to the applied colors and check that the Light selection stays put.
4. Choose a Light palette while in Dark mode. Switch to Light, reload and check both selections. In System mode, flip the OS appearance and check that each saved palette applies.
5. Resize Settings through a wide and narrow layout. Use Tab and arrow keys to choose cards, inspect the full name with focus and confirm the checkmark is distinct from focus.
6. With a custom theme selected in the desktop app, remove its file and reopen Settings. Verify the group uses the default.
