# Data Model

| Giá trị | Nguồn và vòng đời | Mục đích |
| --- | --- | --- |
| Đường dẫn gốc | Bản ghi tệp, project hoặc sự kiện công cụ | Định danh đích cho mọi thao tác |
| Thư mục cá nhân | Tài khoản hệ điều hành, lấy khi mở cửa sổ | So khớp tiền tố ở ranh giới thư mục |
| Nhãn hiển thị | Tính từ hai giá trị trên mỗi lần dựng giao diện | Hiển thị trước bước cắt chữ |

Trạng thái thư mục cá nhân chuyển từ đang chờ sang có giá trị hoặc không khả dụng. Chỉ trường hợp có giá trị mới rút gọn nhãn.
