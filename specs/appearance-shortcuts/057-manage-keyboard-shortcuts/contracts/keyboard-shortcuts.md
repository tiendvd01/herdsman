# Keyboard Shortcuts UI Contract

Settings → Keyboard Shortcuts hỗ trợ tìm kiếm, đổi tổ hợp, lưu, hủy và khôi phục. Khi có xung đột, hiện tên lệnh đang dùng tổ hợp. Command Palette, nhãn UI và menu native dùng tổ hợp hiệu lực.

Tab số 1–9 được chọn theo vị trí hiển thị. Close Tab dùng nút đóng của tab đang chọn. Cửa sổ vẫn mở khi hàng tab trống. Hộp thoại đang mở ưu tiên nhận phím.
