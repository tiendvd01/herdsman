# Quickstart — Code font size

Chạy `pnpm test`, `pnpm typecheck` và `pnpm build`. Mở app và dùng **− / +** tại **Settings → Appearance → Code font size** để chỉnh đến 18 px.

1. Kiểm tra code nội tuyến, code block, file editor, diff và Log. Đổi cỡ chữ văn bản bằng phím tắt và xác nhận code vẫn dùng 18 px.
2. Mở lại app, xác nhận 18 px. Bấm Reset rồi mở lại để kiểm tra cỡ mặc định.
3. Kiểm tra 10 px và 24 px trong theme sáng và tối.
