# Research — Code font size

Code block, diff và Log dùng `text-content-code`. File editor đặt cỡ chữ trên vùng cuộn CodeMirror. Dùng một token kích thước cho cả hai. Code nội tuyến tiếp tục dùng tỷ lệ hiện tại khi chọn Default và dùng cỡ được chọn khi có giá trị cụ thể.

Dùng override tùy chọn để người dùng hiện tại tiếp tục thấy cỡ chữ code theo thiết lập nội dung cho đến khi chủ động chọn cỡ riêng. Hai nút tăng giảm cập nhật giá trị theo bước 1 px. Reset quay về cỡ theo thiết lập nội dung.
