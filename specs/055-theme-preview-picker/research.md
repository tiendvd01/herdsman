# Research

- **Selection** uses existing radio groups and theme preference setters. Radios provide arrow navigation and announce selection. Separate groups preserve independent choices. Dropdowns hide the previews.
- **Grid** uses container breakpoints to follow the available Settings width. Window breakpoints cannot account for the dialog navigation column.
- **Palettes** use the existing resolved theme roles for both previews and app colors. The default palettes and IDs stay compatible. Base colors come from [Catppuccin Frappé](https://catppuccin.com/palette/) and [One Dark Pro](https://github.com/Binaryify/OneDark-Pro/blob/master/themes/OneDark-Pro.json). Map colors to Herdsman roles and verify contrast with the existing checker.
