# Files Tree Contract

- `project_files_list` có thể trả về `ignored: true` cho tệp và thư mục Git bỏ qua. Tên, đường dẫn, thứ tự và loại mục tiếp tục dùng hợp đồng hiện có.
- Tên của mục bị bỏ qua dùng màu chữ phụ. Điều hướng, trạng thái chọn và tiêu điểm dùng hành vi hiện có.
- Khi Git không trả được phân loại, cây vẫn có thể hiển thị kết quả đọc thư mục. Kết quả tìm kiếm vẫn dùng cách trình bày cũ.
